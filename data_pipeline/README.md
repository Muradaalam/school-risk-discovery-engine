# Data Pipeline

This module implements the data and intelligence workstream
of the School Risk Discovery Engine.

## Responsibilities

- Public data acquisition
- Raw record preservation
- Data normalization
- School entity resolution
- Evidence and event extraction
- Issue lifecycle analysis
- Explainable inspection priority
- Data analytics

## Initial Sources

- Rajasthan ShalaDarpan
- Rajasthan eProcurement
- Rajasthan Council of School Education
- UDISE/OGD, where accessible

## Run

From the repository root:

python -m data_pipeline
